#### **[ UUID ]**

!>`uv add uuid-utils`<span style='color:red'>[ 注意事项：`langchain`包内间接引入`uuid-utils < 1.0`]</span>

```csharp
import uuid_utils as uuid
v1 = uuid.uuid4()   # 随机 UUID
print(v1)

v2 = uuid.uuid7()   # 时间有序 UUID
print(v2)


```
